# Shared Service-Page Template

Every one of the four main service pages (Trademark, Copyright, Patent, Privacy Policy) uses this same content skeleton, so the site feels consistent and a returning user always finds things in the same place. Fill each section from the corresponding per-service content file in `/pages`.

This is a **content structure**, not a layout. The implementer decides presentation.

## Required sections, in order

### 1. Page title + one-line definition
The service name and a single plain sentence stating what it is and what it protects.

### 2. Primary action (top placement)
The single obvious next step — start an enquiry for this service. Pre-tags the service so the enquiry form knows the context.

### 3. "Is this for you?" / Who needs it
2–4 short statements letting each relevant audience segment self-identify.

### 4. What's included / What you get
The concrete deliverable(s). What the customer walks away with.

### 5. Key facts strip (scannable)
The handful of facts a buyer scans for first:
- Governing law / authority
- Validity / term
- Typical timeline (flagged as government-dependent)
- Starting cost driver (link to Pricing)

### 6. Types / categories (if applicable)
e.g. trademark mark types & classes; copyright work categories; patent application types. Skip cleanly if a service has none.

### 7. The process — step by step
The full journey as a numbered sequence, **including dispute/failure branches** where they exist (objection, hearing, opposition, etc.). Each step: what happens, who does it, and any deadline attached.

### 8. Documents / inputs required
Exactly what the customer must provide. A checklist the user can prepare from.

### 9. Timeline detail
Honest end-to-end timing, with the clear caveat that government stages are outside anyone's control.

### 10. Cost drivers
What makes the price go up or down (number of classes, published vs unpublished work, provisional vs complete, etc.). Link to Pricing. Do not hard-promise a single number in prose — reference maintainable values.

### 11. Related services
Links to adjacent services and to this service's own sub-pages.

### 12. FAQ
Service-specific questions, marked up for rich results. Minimum 5 questions. Must address the buyer's real hesitations (Is it mandatory? What if it's rejected? How long really? Can I do it myself?).

### 13. Primary action (bottom placement — repeated)
Repeat the enquiry entry point at the end for users who read all the way down.

### 14. Legal disclaimer reference
The site-wide disclaimer (not legal advice; outcomes depend on authorities) is present via the global footer, but service pages dealing with process should not contradict it.

## Consistency rules

- Same section order on all four service pages.
- Same terminology for the primary action across the whole site.
- Every deadline mentioned in a process step is stated in the same format site-wide.
- Sub-pages (e.g. trademark objection) use a **trimmed version** of this template: definition → deadline (if any) → what's included → process → documents → FAQ → primary action.
